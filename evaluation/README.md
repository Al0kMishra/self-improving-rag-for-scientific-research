# Evaluation

- `questions.json`: 24 AI/ML research questions, each with a held-out paraphrase.
- `run_experiment.py`: runs the Baseline vs Self-Improving protocol (warm-up, training cycles, frozen held-out test) and exports `results/<run>/queries.csv` and `summary.json`.
- `plot_results.py <run>`: builds the charts and `report.md` from those exports.

Everything in `results/` is generated by these scripts from stored query records. See the Experiments section of the top-level README for the protocol.
